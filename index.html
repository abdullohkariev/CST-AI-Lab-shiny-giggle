How it works

The same simple idea powers every tool.

1

You write a prompt

A sentence like “a dragon flying over a city at sunset”, or the text you want spoken.

2

A small Python server sends it to the AI

The request goes to the Pollinations API with a secret key. The key stays on the server, so visitors never see it.

GET https://gen.pollinations.ai/image/{prompt}?model=flux&width=1024&height=1024
3

The model creates the result

Flux draws the picture, a text-to-speech model creates an MP3, and Whisper turns speech back into text.

4

You see or hear it

The finished file is sent back and shown on this page. The command-line scripts also save every result to an output folder.

5

The school website works differently

It is plain HTML, CSS and JavaScript written with Claude. Its chatbot is rule-based: it matches keywords to answers from the site's own content, so it needs no AI service and sends no data anywhere.
